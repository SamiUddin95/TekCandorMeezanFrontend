Audit Framework Information

The audit framework captures Who, What, When and IP Address for relevant system activity. This includes user login/access, file upload/import, authorization, manual intervention, deletion/cancellation, reversal and other material transaction actions. Audit records are protected from unauthorized modification and made available through controlled audit reporting.
